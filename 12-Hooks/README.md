## What are Hooks?
.Hooks are special functions in React that let you use state and other React features inside functional components. They always start with the word use, like useState and useEffect.
## Why we need Hooks?
.Before hooks, functional components were "dumb": they could only display UI. They couldn't hold state or run code at specific moments. For anything useful you had to write class components, which had several problems. Hooks were created to solve them
## HIstory of hooks?
.Before hooks (before React 16.8), state and lifecycle features worked only in class components. Hooks made it possible to do all of this in simple functions.

## Some Hooks name?

## HOW to identify HOoks?
1. The name starts with (use)
Every hook follows this naming rule: (useState), (useEffect), (useRef), (useFetch). If a function starts with use followed by a capital letter, it is a hook.

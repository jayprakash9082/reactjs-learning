# What is browser router?
BrowserRouter is a React Router component that uses the browser's History API to manage client-side routing and navigation in a React application.
# What is routes?
Routes is a React Router component that contains and manages multiple Route components and renders the route that matches the current URL.

# What is Route ?
A Route defines a mapping between a URL path and the React element that should be rendered when that path matches the current URL.

# what is link ? 

Link is a React Router component used to navigate between different routes without reloading the entire page
